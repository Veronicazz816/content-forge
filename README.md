# ContentForge - AI Content Creation Workflow

An AI-powered multi-platform content creation and distribution tool built with React and LLM APIs.

## Features
- Multi-platform content generation (Xiaohongshu, WeChat, Zhihu, X/Twitter)
- Multiple content types (articles, short posts, threads, summaries)
- Token usage tracking and cost optimization
- Publishing history and analytics dashboard

## Tech Stack
- Frontend: React
- AI: Claude Code + LLM API integration
- Planned: Xiaomi MiMo V2.5 integration for enhanced Chinese content generation

## Usage
Built with Claude Code as the primary development tool.
Daily output: 5-8 cross-platform content pieces.
